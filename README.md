# 🏥 AI Disease Prediction System

An ML-powered disease prediction system that analyzes symptoms and predicts the most likely disease with AI-powered health advice.

## 🚀 Features
- 🤒 Select from 35+ symptoms
- 🤖 Random Forest ML model predicts top 3 diseases with confidence scores
- 🧠 Groq + LLaMA 3 gives detailed health advice and precautions
- 📊 Visual confidence bars for each prediction
- ⚠️ Covers 15 common diseases

## 🛠️ Tech Stack
- Python, Scikit-learn (Random Forest)
- Groq API + LLaMA 3.3 70B
- Streamlit, Pandas, NumPy

## ▶️ How to Run
```bash
git clone https://github.com/rohithvandadi07-ux/disease-prediction.git
cd disease-prediction
pip install -r requirements.txt
streamlit run app.py
```
